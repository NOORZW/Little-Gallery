🖼️ Little Gallery Save Editor

Edit your save through the game's own Backup & restore code. Nothing here touches the game's files, and everything stays in your browser.

How to use it

  1. In the game, open the Career tab, click Backup & restore save, and copy the code.
  2. Paste it below and click Decode, then change whatever you like.
  3. Copy the new code from the bottom of this page. In the game, open Backup & restore, paste it, and click Load pasted code.
Tip: copy your original code somewhere safe first so you can always go back. Close any other Little Gallery tabs while you load the new code.
